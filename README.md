# ITI PD Intake 46 – C# Labs - 2026 🧪

This repository contains a collection of **C# labs and mini-projects** completed during the **ITI Professional Diploma (PD)** program.  
The labs focus on building a strong foundation in **C# fundamentals**, **Object-Oriented Programming (OOP)**, and **Windows Forms desktop application development** through hands-on practice.

Each folder represents a lab or exercise where specific concepts were learned and applied.

---

## 🎯 Objectives

The main goals of this repository are to:
- Practice C# syntax and problem-solving
- Apply Object-Oriented Programming principles
- Understand event-driven programming
- Build simple desktop applications using WinForms
- Write clean, structured, and reusable code

---

## 🧠 Key Topics & Learnings

### 🔹 C# Fundamentals
- Program structure and execution flow
- Variables and built-in data types
- Operators and expressions
- Conditional statements (`if`, `switch`)
- Loops (`for`, `while`, `foreach`)
- Console input/output
- String formatting and interpolation

---

### 🔹 Object-Oriented Programming (OOP)
- Classes and objects
- Properties, methods, and constructors
- Encapsulation and access modifiers
- Inheritance
- Polymorphism and method overriding
- Abstract classes
- Interfaces
- Static members
- Delegates and events

These concepts were applied to design modular, maintainable, and reusable code.

---

### 🔹 Windows Forms (WinForms)
- Creating WinForms projects using Visual Studio
- Designing user interfaces (labels, textboxes, buttons)
- Event-driven programming
- Handling user input
- Performing calculations based on UI interaction
- Separating business logic from UI logic
